# 空き家レスキュー 公式サイト 第3版

無料会員基盤＋地域情報配信＋会員限定実家現地確認＋提携事業者成果報酬型へ全面再構成した静的サイトです。

## 現在の状態
- 無料会員登録・現地確認相談はメール作成方式で受付
- オンライン決済・会員データベースは未接続
- 検索エンジンは noindex と robots.txt で停止
- Cloudflare Pages等へアップロード可能

## 公開前の必須対応
1. 公開URLを site-config.js の currentUrl へ反映
2. フォームサービスまたはCRMを選定してメール作成方式から移行
3. オンライン決済を導入する場合、決済ページと最終確認画面を作成
4. 地域情報配信の同意・配信停止を管理できるメール配信サービスを接続
5. 正式営業開始時に noindex と robots.txt を解除
