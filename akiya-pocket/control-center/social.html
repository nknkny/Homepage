最初の本人作業
ここだけは各SNS側の本人ログイン・Developer登録・同意画面のため、本人操作が必要です。Client Secretは保存時にSupabase Vaultへ格納され、画面へ再表示しません。

Instagram

  1. 空家ポケット公式InstagramをBusinessまたはCreatorのプロアカウントにする。
  2. Meta for Developersでアプリを作成し「Instagram API with Instagram Login」を設定する。
  3. 下記Callback URLをValid OAuth Redirect URIに登録する。
  4. Instagram App ID / App Secretをこの画面へ保存する。
  5. 「Instagramで本人認証」を押して許可する。

X

  1. 空家ポケット公式Xアカウントを用意する。
  2. X DeveloperでProject/Appを作り、OAuth 2.0を有効にする。
  3. 権限は投稿可能なRead and write相当、Callback URIに下記URLを登録する。
  4. Client ID（Confidential ClientならClient Secretも）をこの画面へ保存する。
  5. 「Xで本人認証」を押して許可する。
