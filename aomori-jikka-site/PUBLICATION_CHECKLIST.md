# 公開・営業開始チェックリスト

## URLだけ先に取得する場合
- [ ] このサイト一式をCloudflare Pagesへアップロード
- [ ] 発行されたURLを控える
- [ ] `site-config.js` の `currentUrl` に入力して再アップロード

## 問い合わせ受付前
- [ ] 屋号、氏名、住所、電話、メールを入力
- [ ] 対応地域3区分と加算額を入力
- [ ] 営業時間を確定
- [ ] 問い合わせフォームを作成しURLを入力
- [ ] 利用規約・プライバシーポリシーを最終確認

## 決済開始前
- [ ] 決済方法と課金日を確定
- [ ] 月額決済ページを作成
- [ ] 巡回決済ページを作成
- [ ] 解約フォームを作成
- [ ] 最終確認画面で料金、継続課金、追加費用、解約方法を表示
- [ ] スポット巡回キャンセル条件を確定
- [ ] `serviceStatus` を `live` へ変更
