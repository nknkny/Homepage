# ローカルスペース — 初期事業戦略 v2

## 一文で定義

**使われていない小さな場所と「ここで何かやりたい」をつなぎ、決まった催しを地域のイベントカレンダーへ変換する。**

## 初期の3面

1. **SPACE** — 空き地、店先、店舗の一部、駐車スペース等を一時利用に出したい人。
2. **WANT** — ポップアップ、ライブ、展示、ワークショップ、物販等のため場所を探す人。
3. **EVENT** — 開催が決まった超小規模イベントまで載せるローカルカレンダー。

出演者、広告会社、運営スタッフ等の別市場は初期版から外す。最初に「場所が見つかる」「小さい催しも見つかる」の2価値を成立させる。

## 成長ループ

SPACE掲載
→ WANTが検索・客観条件で照合
→ 外部で直接連絡・合意
→ WANTをEVENTへ変換
→ カレンダー掲載 + 希望者は無料簡易SNS告知候補
→ 地域住民がイベントを発見
→ 主催者・場所提供者がサービスを知る
→ SPACE/WANTが増える

## 初期の差別化

自治体・観光サイト等が拾いやすい大規模イベントではなく、公式カレンダーに載りにくいロングテールを狙う。

- 1日だけの店先ポップアップ
- 数時間の小ライブ
- ハンドメイド販売
- 個人展示
- 小さなワークショップ
- フード系の短時間出店（必要な許可は主催者側）
- 学生・クリエイターの小企画

サイトの「場所探し」と「イベント発見」を分離せず、一つのデータ循環にする。

## 初期顧客獲得

### 供給側を先に作る

場所の密度がないと需要側が定着しない。最初は青森市の限定エリアで手動営業し、在庫密度を作る。

優先候補:
- 店先・軒先を持つ小売店
- 飲食店の休業時間帯・外部スペース
- ギャラリー・スタジオ
- 空き駐車場・私有地
- 空きテナント等の所有者・管理者（運営者は取引媒介しない）
- 寺院・コミュニティ施設等、管理権限者が一時利用を許諾できる場所

訴求は「空いている時間・場所を、まず無料で見つけてもらう」。

### 需要側

- ハンドメイド作家
- 小規模物販
- ミュージシャン・表現者
- 学生団体
- ワークショップ主催者
- 地域の個人事業者
- キッチンカー等（営業許可等は各自確認）

「会場を探せる」に加え、「開催後に無料でカレンダー掲載・簡易告知候補になる」を付加価値にする。

## KPI（実績値ではなく初期検証目標）

正式公開後、全国へ薄く広げず青森市で密度を見る。

- 公開SPACE: 30件
- 有効WANT: 月20件
- EVENT掲載: 月30件
- WANT→開催決定: 月5件以上
- 外部問い合わせクリック率
- SPACE 1件あたりの候補WANT数
- カレンダーのリピート閲覧率

数値は市場実績ではなくPMF検証用の暫定目標。実データで更新する。

## 収益化の順序

### Phase 0 — 無料

- SPACE/WANT/EVENT掲載無料
- 検索・客観マッチ無料
- イベントカレンダー無料
- 簡易SNS告知は希望制・無料、効果保証なし

まず流動性とデータを作る。

### Phase 1 — 取引非連動の広告・露出課金

法務境界を維持したまま収益化しやすい候補:
- カレンダー注目枠
- 特集記事
- SNS用告知クリエイティブ制作
- 有料SNS広告運用代行
- 固定期間の掲載強化

料金は「契約成立額の○%」ではなく、掲載期間・制作物・広告作業等に対する固定対価として設計する。

### Phase 2 — 予約・成功報酬

本来構想の場所代○%手数料は、事業固有の行政確認または必要な免許・提携体制を確定してから実装する。確認前には販売しない。

競合料率は将来のベンチマークにはなるが、そのままコピーしない。平均場所単価、CAC、決済費、キャンセル率、サポート原価、法務体制が揃ってから決める。

## 主要リスクと設計対応

- **宅建業該当:** 個別取引への関与・成功報酬をOFF。
- **無権限掲載:** 掲載時に権限確認を必須化、通報・自動非公開。
- **公共空間の誤掲載:** 公道・公園を許可なく貸せる場所として掲載禁止。
- **イベント固有許認可:** 主催者責任を明示。
- **コールドスタート:** 青森市の狭いエリアで供給側から密度を作る。
- **イベント情報不足:** WANT→EVENT変換を簡単にする。
- **無料告知の工数:** 初期は「告知候補」とし、自動SNS投稿はAPI・権利・運用確認後に実装。
- **偽情報:** 管理鍵、レート制限、禁止語、自動審査、独立通報3件で自動非公開。

## 初期にやらないこと

- 全国同時展開
- 求人市場
- 出演者・広告会社・スタッフ等の別マーケットプレイス
- サイト内チャット
- 予約・決済
- 成約手数料
- 場所契約の代行

**小さな場所 × 小さな催し × ローカルカレンダー** の流動性を最優先にする。
